the precautions to take and the tests to run afterwards. Planned rows include:

- changing a numerical parameter (quadrature orders, `fill_mode`, GPU threshold, CMA solver);
- a new quadrature rule or singularity treatment;
- a new basis function;
- a new excitation or port model;
- a different linear solver;
- a new post-processed quantity or plot;
- a new high-level algorithm.
