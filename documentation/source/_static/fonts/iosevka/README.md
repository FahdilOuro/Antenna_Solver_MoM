# Iosevka (web fonts)

Iosevka by Belleve Invis, version 22.1.2, licensed under the SIL Open Font License 1.1
(`LICENSE.txt`, which must stay next to the font files).

The four `.woff2` files come from the npm package `@fontsource/iosevka` 5.3.0
(<https://fontsource.org/fonts/iosevka>), downloaded on 2026-11-11. Each file holds the full
character set used by the site (Latin, Greek, mathematical symbols).

| File | Weight | Style |
|---|---|---|
| `iosevka-latin-400-normal.woff2` | regular | normal |
| `iosevka-latin-400-italic.woff2` | regular | italic |
| `iosevka-latin-700-normal.woff2` | bold | normal |
| `iosevka-latin-700-italic.woff2` | bold | italic |

They are declared in `../../css/custom.css` (`@font-face`).
